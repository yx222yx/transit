## 3. 统一样本与应用矩阵

英语样本：`Walking a little more slowly changes the scene.`

中文核对要点：放慢脚步会改变眼前的景象。

俄语样本：`По утрам я часто иду одной и той же дорогой.`

中文核对要点：早晨经常沿着同一条路走。允许自然表达不同，不以逐字相同判定翻译质量。

对每个可选文字场景执行相同流程：先关闭自动划译，用左键选择一个单词、一整句，再跨行选择，分别按 `Ctrl+Alt+T`；确认取得的原文范围与选择一致。随后开启自动划译，重复左键拖选，松开后应自动出现近旁浮窗；重新选择下一句应更新结果。每种语言都执行一次。取词不支持时记录实际反馈，再用界面显示的实际框译热键验证补充路径（本机为 `Ctrl+Alt+Shift+Q`）。
