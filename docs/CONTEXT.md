# 随译阅读辅助术语

随译帮助用户阅读屏幕上的英语、俄语内容。本词表区分已有阅读方式与已确认的新阅读方式；术语本身不代表功能已经实现。

## Language

**划译**：针对用户在原应用中选中的文字提供中文译文的阅读方式。
_Avoid_：框译

**框译**：针对用户框定的一块屏幕画面中的文字提供中文译文的阅读方式。
_Avoid_：划译

**持续翻译**：用户开启后，随指定范围中的内容变化而持续更新中文译文的阅读方式。
_Avoid_：自动划译（现有功能中指每次划选文字后触发翻译）

**分析侧栏**：在阅读内容旁边，展示模型对该内容的分析、建议和提示的辅助阅读面板。
_Avoid_：译文（分析和建议不属于原文的翻译）

**覆盖翻译**：在原文字所在位置展示中文、隐藏其下原文字的视觉阅读方式，原应用和文件内容不因此改变。
_Avoid_：改写原文件

**阅读会话**：一次持续阅读及用户允许用于分析的有限已读内容组成的上下文，可结束或清空后重新开始。
_Avoid_：永久浏览历史

**目标窗口**：用户选定的持续翻译对象，选区与它一起移动；它关闭后本次持续翻译结束。
_Avoid_：任意前台窗口
